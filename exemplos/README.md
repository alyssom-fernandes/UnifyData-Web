# Arquivos de exemplo

Arquivos 100% fictícios, no mesmo formato dos relatórios do Linx e das planilhas do RH, para testar o UnifyData sem dados reais. Nomes, empresas e CPFs foram inventados; os CPFs têm dígitos verificadores inválidos de propósito.

*Made-up files in the same format as the Linx reports and HR spreadsheets, for trying UnifyData without real data. Names, companies and CPFs (the Brazilian taxpayer ID) are invented; the CPFs deliberately have invalid check digits.*

| Arquivo / File | Etapa / Step | Conteúdo / Contents |
|---|---|---|
| `Contas a Receber.pdf` | 1. Base | Matrícula, nome e CPF de 22 pessoas |
| `Empregados Auto Peças Horizonte.xlsx` | 1. Base | RH de uma empresa |
| `Empregados Hotel Primavera.xlsx` | 1. Base | RH com duas abas (Matriz e Filial) |
| `Empregados Posto Serra Azul.xlsx` | 1. Base | RH de uma empresa |
| `LOJA.csv` | 2. Consumos | Pendências por responsável de uma loja |
| `RESTAURANTE.csv` | 2. Consumos | Pendências por responsável de outra loja |

Com esses arquivos aparecem quatro pendências: duas pessoas sem cadastro (estão no Linx, mas não no PDF) e duas sem empresa (estão no PDF, mas em nenhuma planilha do RH).

*With these files, four pending items show up: two people with no register entry (in Linx, but not in the PDF) and two with no company (in the PDF, but in no HR spreadsheet).*
